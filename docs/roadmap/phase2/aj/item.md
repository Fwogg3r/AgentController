Agent text in every transcript (Claude Code sessions, API runs, one-shots, roadmap cards) renders as markdown: headings, bold/italic/strikethrough, inline code and fenced blocks, nested and numbered lists, task lists, tables with alignment, blockquotes, rules, links (http/https/mailto/relative only; bare URLs become links). Escape-first, so transcript HTML never runs. A text block stays clickable for forwarding (the raw text is forwarded).

Notes: checked on the live dashboard with this session's transcript. No syntax highlighting in code blocks.
